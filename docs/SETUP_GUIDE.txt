MALLVR - SETUP GUIDE
===========================

1. UNZIP
   Unzip the whole folder to a place you can write to, for example
   C:\Games\MallVR. Avoid C:\Program Files.

2. GAME FILES
   This download has no game files. Get them from archive.org:
     - SU2000 games (Dactyl Nightmare 1 + 2, Pac-Man VR, Missile Command, Olin Shotgun,
       Boxing, Zone Hunter, Ghost Train, Shoot For Loot, Sea Diving):
       https://archive.org/details/su2000-hdd-files
       (inside: the "VR 2000 Series Disc Image (Simon's)" folder)
     - Pac-Man VR CD image, PACMAN.CUE + PACMAN.BIN (inside its pacman.zip):
       https://archive.org/details/drive-download-20240331T000417Z-001
     - Total Recoil, Zero Hour + Zeneca Migraine (SU3000 drive, su3000.zip):
       https://archive.org/details/su3000
     - Buggy Ball game data (Buggy.7z; MallVR rebuilds the game, the original BALL.EXE is lost):
       https://archive.org/details/buggy.-7z
   Unzip each one, as it is, into the games folder. Subfolders are fine - the
   launcher searches the whole games folder. Do not rename the game folders.
   Example:
     games\VR 2000 Series Disc Image (Simon's)\DAC\DAC.EXE
     games\Pac-Man CD\PACMAN.CUE
     games\su3000\ZERO\ZERO.EXE
     games\Buggy\BALL\RUNFILES\CARS.DBS

3. CHECK
   Double-click Check_My_Games.bat. Every game should say READY.
     READY      the exact version this build was made for
     READY?     a different version of the game - it may still work
     NEEDS CD   Pac-Man VR is there but its CD image is not
     MISSING    the game is not in the games folder

4. PLAY
   Turn on the headset first, then double-click Play_<game>.bat. SteamVR starts on
   its own if it is not running. The game opens in a window on the monitor (a mirror
   of your left eye) and in the headset. Close that window to quit.
   Stand in the middle of your play space and face forward before you start.

5. YOUR SETTINGS
   Gun aim feels high or low? Index: touch near the top / bottom edge of the LEFT
   touchpad. Vive: LEFT touchpad up / down. Keyboard: arrow up / down. Arms too short or
   long (Boxing, the guns)? Index: RIGHT touchpad left / right edge. Vive: LEFT touchpad
   left / right. Keyboard: arrow left / right.
   Both are saved per game in settings\ for next time.

6. UPDATES
   When you start MallVR or a game it checks online for a newer version (a second or
   two) and installs it by itself, about a minute, then your game starts. Updates never
   touch the games, settings or logs folders. No internet? The game just starts.

   To check yourself at any time, run Update.bat.

3D SIDE-BY-SIDE (a head-mounted display that takes a 1920 x 1080 SBS picture)
   In the launcher pick WINDOW, then click 3D OFF until it says 3D SBS or
   3D HALF-SBS. MallVR then opens a borderless 1920 x 1080 window: left eye in
   the left half, right eye in the right half, each at the game's own 4:3.
     3D SBS       each eye 960 x 720, black bars above and below
     3D HALF-SBS  each eye squeezed to 720 x 1080; for displays that stretch
                  each half back to full width (it then shows 4:3)
   Which screen: add a line  sbs_monitor = 2  to settings\launcher.txt (1, 2,
   3 ... in the order Windows lists them; logs\<game>.render lists them with
   their positions). Without it the window opens on the main display.
   Adjust it with the headset on (keys work while the 3D window is in front;
   values show in the picture and are kept for next time):
     F1 show / hide the values      F2 / F3   eye distance (3D strength)
     F4 / F5 picture size           F6 / F7   pictures closer / apart (lenses)
     F8 / F9 picture down / up      F10       swap left / right eyes
     F11 SBS <-> HALF-SBS           F12       depth of the score / text
     Page Down  next screen         Page Up   detail 100 / 75 / 50 % (slow PC)
     Home  reset all                Esc       quit
   If the keys do nothing, click inside the 3D picture once. If the 3D looks
   inside out or hurts, press F10. Mouse + keyboard play as in window mode
   (docs\CONTROLS.txt). Works without SteamVR, so Windows 7 64-bit is fine for
   this mode once PowerShell 5.1 is installed.

FIXING PROBLEMS
   Nothing happens / a box says the game was not found
       Run Check_My_Games.bat and fix what it reports.
   Game opens on the monitor but not in the headset
       Start SteamVR first and make sure the headset shows as connected (green).
   Black screen in the headset for a few seconds
       Normal while the game loads its models. Dactyl Nightmare takes about 5 s.
   Windows SmartScreen warns about the .bat files
       Click "More info" then "Run anyway". The scripts are plain text - open them in
       Notepad to see exactly what they do.
   Something else
       The logs folder has <game>.calls and <game>.render after each run. Include
       them when you report a problem.

KNOWN LIMITS
   Every game runs with free play. Dactyl Nightmare is the only game that links
   pods for multiplayer (docs\MULTIPLAYER.txt); the others, Shoot For Loot
   included, run single-player.
