v0.15.0 (November 2026) - THE LOST GAMES

v0.12.1 (October 2026) - GET GAMES

  - NEW: GET GAMES. Press it at the bottom of the game select screen (it opens by itself if MallVR
    finds no games): MallVR downloads the game files from archive.org, checks them and puts them in
    the right place. No unzipping, no folder hunting. About 550 MB for all 14 games. Works in the
    headset panel too. (Windows 10: if it can't unpack a .7z file, it says so and keeps the download.)
  - The game select screen shows how many players are online right now, next to ONLINE.
  - Button Masher Menu > VOICE CHAT: MY MIC shows LIVE or MUTED (click to switch), and PUSH TO TALK
    on / off (hold the left stick to talk). Kept for next time.
  - CHECK GAMES points you to GET GAMES when games are missing.
  - Online matches get a match number in the play notes (groundwork for high scores and tournaments).

v0.12.0 (October 2026) - online with Meta Quest players (TEST)

  - CROSSPLAY: PC and Meta Quest players (MallVR for Quest 0.2) are in one ONLINE list and play the
    same linked games together: QUICK MATCH, HOST, JOIN, and groups that stay together between games.
    Each player shows PC or QUEST. This is new: if it works or breaks, press REPORT A PROBLEM.
  - VOICE CHAT with Quest players too. NEW on the Button Masher Menu: VOICE CHAT, turn each friend
    up or down (0-200 %) or mute them. Only changes what you hear; kept for next time.
  - Safer online play: the online list no longer shows anyone's home internet address (you only get
    the address of the host you join), and the game's network port only listens on your own PC
    during online play. A host turns away a player whose game files are a different version.
  - QUICK MATCH on ANY GAME no longer waits forever when two players host games the other lacks.
  - Updates are now signed: MallVR only installs updates made by us.
  - Older versions can still see who is online but can't join internet games: update when asked.

v0.11.2 (October 2026) - fixes from your bug reports, thank you

LAUNCHER
  - The launcher now shows up inside your headset (HEADSET mode, SteamVR running): point with
    your controller and pull the trigger to pick a game, START, go online.
  - NEW: the BUTTON MASHER MENU in every game. PRESS AND KEEP HOLDING A + B together (Vive wands:
    both menu buttons) until the menu appears, about a second. A quick press does nothing. RESUME,
    BACK TO MENU, SWITCH GAME (online groups), REPORT A PROBLEM and PLAY NOTES, without taking the
    headset off.
  - NEW: REPORT A PROBLEM (game select screen and the Button Masher Menu). Type one line about
    what went wrong; it goes to us with the logs of that game (your Windows user name is cut out
    of them). If it can't be sent, the file lands on your Desktop: drag it into our Discord
    #bug-reports. If a game closes by itself, MallVR offers this straight away.
  - NEW: PLAY NOTES, asked once the first time you start this version. Say YES and MallVR sends us
    anonymous notes: which games you play and for how long, frame rate, your headset and graphics
    card, crashes and online connection problems. No names, no files. Off unless you say yes;
    PLAY NOTES ON / OFF on the game select screen changes it any time. Details:
    gainesphere.com/pages/mallvr-privacy
  - Total Recoil and Zero Hour start from MallVR_Launcher.bat and show up in Check My
    Games with the folder and file names they have on archive.org (GUN\GUN.EXE and
    ZERO\ZERO.EXE). No renaming needed any more.
  - 32-bit Windows: MallVR now says plainly that it needs 64-bit Windows 10 or 11,
    instead of a game that never opens.

ONLINE GROUPS
  - A group now stays together after a game. You're back on the ONLINE screen with the same
    players: the host presses START for another round, or clicks the game name to pick another
    game (only games everyone in the group has).
  - SWITCH GAME in the middle of a game: the host holds A + B for the Button Masher Menu and picks
    SWITCH GAME. Everyone else sees "<HOST> WANTS TO PLAY <GAME>" with GO / STAY OUT for 10
    seconds (no answer = GO). Then every PC closes its game and opens the new one, linked again.
    STAY OUT = you leave the group. In window mode the question is a small window on top.
  - Everyone in a group needs v0.11.2 or newer to switch games. Older versions can still join
    a normal game; MallVR now also refuses a player whose online version can't link with yours,
    instead of a game that breaks.

META QUEST
  - Quest / Oculus Touch controllers get their own MallVR layout in SteamVR.
  - HOLD Y to adjust: left stick = gun aim, right stick = arm reach. See docs\CONTROLS.txt.

VIRTUALITY BOXING
  - If your punches don't count in the ring (reported on Quest), use the keyboard: Right
    arrow = a shorter jab lands, Left arrow = longer; Up / Down = arm height; [ ] = glove
    spread. Saved for next time. Optional: punch tracking is unchanged unless you press them.
  - Two-player Boxing: both players need v0.11.2.

PAC-MAN VR
  - Walk with the triggers: RIGHT trigger forward, LEFT trigger back (the sticks still work).
  - VR: the score and lives are pulled in from the edge of the lenses.

GHOST TRAIN
  - The sight lines up with your shots.
  - Name entry letters at the end: the drop shadows are black again (the letters looked doubled).
